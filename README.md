# Curadoria — Objetivo Baixada

Projeto isolado para curadoria de referências e apoio à comunicação das seis unidades do Colégio Objetivo na Baixada Santista.

## Isolamento

- Repositório: `hermes-ia-gsp/curadoria-objetivo-baixada`;
- GitHub Pages: `https://hermes-ia-gsp.github.io/curadoria-objetivo-baixada/`;
- configuração, memória, histórico, artefatos, destinatários e automações próprios;
- nenhum arquivo, URL, segredo ou destinatário de outra escola deve ser reutilizado aqui.

## Unidades

1. Praia Grande
2. São Vicente
3. Guarujá
4. Santos — Ponta da Praia
5. Santos — Embaré
6. Santos — Conselheiro Nébias

## Escopos de saída

- `arquivo/geral/`: curadorias da marca/grupo;
- `arquivo/unidades/<slug>/`: histórico por unidade;
- `out/geral/`: relatórios e páginas do grupo;
- `out/unidades/<slug>/`: relatórios e páginas locais;
- `config/objetivo-baixada.json`: regras compartilhadas;
- `config/unidades/*.json`: ficha operacional individual.

## Status

Estrutura pública em adaptação. A home foi redesenhada com referência visual no site oficial do Objetivo Baixada, preservando a operação editorial independente: hub, agentes, processo, mapa de unidades, arquivo geral, arquivos por unidade, documentação e template de votação.

Antes de anunciar a página como publicada, validar o build do GitHub Pages e a URL pública após o commit.
