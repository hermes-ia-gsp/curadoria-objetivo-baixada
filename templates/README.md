# Templates públicos

Cada referência publicada deve conter:

- unidade e segmento aplicável;
- tema/território;
- fonte pública verificável;
- sinal de performance ou tendência, sem inventar métrica;
- por que funciona e adaptação sugerida;
- formato e CTA;
- botões **Votar para produzir** e **Orientar Tico**.

O script da rodada preenche links Gmail/Outlook sem enviar mensagens automaticamente.
